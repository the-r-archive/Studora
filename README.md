# 📚 STUDORA OS

**A Personal Study Operating System**

STUDORA OS is a web-based study management platform designed to help students organize their academic activities, manage daily tasks, track study progress, and maintain consistency — all from one workspace.

🔗 **Live Website:** [https://studora-os.vercel.app/](https://studora-os.vercel.app/)

---

## 📖 Overview

STUDORA brings essential study and productivity tools together in a single, organized interface. It is designed to simplify everyday study planning and help students stay focused on their academic goals.

The project is independently conceptualized and curated by me, with development supported by AI-assisted coding.

## ✨ Key Features

- **Dashboard:** A centralized overview of study activities and progress.
- **Task Management:** Create, organize, and manage daily study tasks.
- **Focus Tracking:** Monitor study sessions and time spent learning.
- **Study Streaks:** Track consistency and build better study habits.
- **Subject Management:** Organize academic subjects and learning progress.
- **Focus Room:** A dedicated space for focused study sessions.
- **Theme Switching:** Dark mode by default with an option to switch to light mode.
- **Responsive Interface:** Adapted for desktop, tablet, and mobile devices.

## 🚀 Getting Started

To explore STUDORA, visit the live website:

[**https://studora-os.vercel.app/**](https://studora-os.vercel.app/)

To run the project locally:

1. Clone this repository.
2. Open the downloaded project folder.
3. Open `index.html` in your web browser.

## 💾 Data Storage

STUDORA currently uses browser Local Storage to retain user data. Information is stored locally in the browser, so it may not automatically synchronize across different devices or browsers.

Cloud synchronization is a possible future enhancement.
